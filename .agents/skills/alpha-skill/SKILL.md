# 个股预期差分析（alpha-skill）

框架：**市场预期端**（`fin.report_forecast`：分歧度 CV + 上修/下修方向）× **基本面端**（`fin.fina_indicator` 边际动量）× **定价端**（`stock.daily_basic` PE/PB 三年分位）× **观点端**（`fin.report_meta` 近期研报）。实现：`beta_alpha/skills/alpha.py`（平台对话页意图 `alpha` 自动触发）。

## 步骤

1. **确认标的**：用户话术中须含股票名或 `600519.SH` 格式代码；模糊时先向用户确认，不要猜。

2. **执行四象限分析**（项目根目录）：
   ```bash
   .venv/Scripts/python.exe -m beta_alpha.skills.alpha "中际旭创的预期差"
   ```
   输出：指标平表 + markdown 中文综述（约 1 分钟，含 LLM）。预期输出形态见 `assets/output-example.md`。

3. **按口径解读**（阈值定义与 SQL 细节在 `references/quadrant-data.md`，改判定先读它）：
   - 预测分歧度 CV > 0.3 = 分歧大，越小共识越强；方向=后半年均值 vs 前半年（±3% 内持平）
   - 财务动量信号带语境：`高位降速`（如 192%→182%）不等于恶化，`负增收窄`是修复信号
   - PE/PB 分位：低分位=市场预期保守，高分位=预期已计入；样本 <60 天（次新股）返回空属正常
   - 预期差叙事逻辑：**分歧大 + 基本面验证中 + 低分位** = 市场未定价的争议；**共识强 + 高分位** = 预期已打满

4. **数据现状如实说明**（条件分支）：
   - 预测覆盖为空 → 研报库（海外券商为主）暂无该股绑定，是常态而非故障：明说"无覆盖"，引导看其余三象限
   - 用户问管理层指引、在手订单、"CPO 送样"类定性信息 → **超出本框架**（需年报正文语料，规划中 cninfo 通道），说明边界，不要用研报观点硬凑

## 成功标准

- 每个数字来自命令输出；无覆盖/样本不足就明说，禁止编造
- 输出一律简体中文，客观陈述，不写投资建议
- 修改判定阈值/加指标时：只改 `beta_alpha/skills/alpha.py` 的纯函数（`to_yuan`/`classify_drift`/`edge_trend`）并补 `beta_alpha/tests/` 用例，`pytest beta_alpha/tests` 全绿
