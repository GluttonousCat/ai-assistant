# 产业链 Beta 挖掘

三层结构：**知识层**（`beta_alpha/chains/*.yaml` 种子链模板，可编辑）→ **映射层**（环节→标的三源打分，代码在 `beta_alpha/analysis/chain_analysis.py`）→ **量化层**（流通市值加权环节组合 vs 沪深300，120 日窗口）。平台对话页里意图 `chain` 自动走这条链路；本模块让你在 ZCode 会话里直接驱动同一套能力。

所有命令在项目根目录执行，Python 一律用 `.venv/Scripts/python.exe`。数据库（PG）与服务无需常驻——分析命令直连 PG。

## 按需求选路径

| 用户意图 | 做法 |
|---|---|
| 看某条链的环节行情/强弱（不要长文） | 命令 A（纯量化，无 LLM，秒级） |
| 完整分析（量化 + 中文综述） | 命令 B（走 LLM，约 1-2 分钟） |
| 深挖单个环节的标的与证据 | 命令 B 带环节话术 |
| **新增一条链（LLM 生成草稿+命中率闭环）** | `python -m beta_alpha.forge "<主题>"`（用户也可在网页「产业链」页点「＋ 新建链」） |
| **校验/排错已有链（含手写链）** | `python -m beta_alpha.forge --check <chain_id>` |
| 编辑产业链、关键词误报排查 | 读 `references/chain-template-guide.md` 再动手 |
| 主营构成数据同步/回填/监控 | 读 `references/data-ops.md` |

## 命令 A：量化速览（无 LLM）

```bash
.venv/Scripts/python.exe -m beta_alpha.analysis.chain_analysis ai_compute
```

参数是 chain_id（`ai_compute` / `semiconductor` / `robot`，即 yaml 文件名）。输出环节数值表 + 每环节头部标的。列含义：

- `strong/medium`：强档（主营构成中环节业务收入占比≥30%）/中档（10~30%，或行业+研报双命中）标的数。环节指数成分=强+中
- `port_ret_120d / excess_120d / excess_20d`：环节组合收益、对沪深300 的 120 日/20 日超额（%）。`NaN`=成分股不足 2 只
- `or_yoy_median`：成分股最新报告期营收同比中位数（%）
- `report_heat_6m`：近半年 tags/标题命中环节关键词的研报数

标的行 `英维克(强|92.5%)` = 档位|主营构成命中占比。所有数字直接引用，禁止推算或编造。

## 命令 B：完整分析（LLM 综述）

```bash
# 全链
.venv/Scripts/python.exe -m beta_alpha.skills.beta "AI算力产业链有哪些环节"
# 单环节下钻（环节词会被映射到链内节点）
.venv/Scripts/python.exe -m beta_alpha.skills.beta "AI算力链的覆铜板环节有哪些标的"
```

自然语言会先做规则匹配、失败则 LLM 从模板清单选链；输出 = 量化表 + markdown 中文综述。若返回"未找到匹配的产业链模板"，说明话术没命中任何模板——要么换 chain_id 用命令 A，要么按模板指南新增链。

## 解读要点

- **先看结构再看强弱**：120 日与 20 日超额结合，判断上游/下游谁先动（如 CCL +121% 而 IDC -12% = 典型上游先动）。20 日反转 + 高研报热度 = 资金切换信号
- **档位即证据强度**：只有"强/中"进环节指数；"弱"（仅研报提及）只作参考。标的证据串会注明主营构成命中的业务名与占比——发现"汽车板簧"混进"汽车板"这类误报时，按模板指南收紧关键词
- **数据不足要明说**：环节成分 <2 只时指标为 NaN，成因通常是主营构成回填未覆盖（见 data-ops）或披露口径不匹配

## 硬约束

- 输出一律简体中文；面向用户的结论必须基于命令输出，不得凭模型记忆报数字
- 修改模板后必须重跑命令 A 验证该链可用
- 不给投资建议，保持"结构描述 + 证据引用"
