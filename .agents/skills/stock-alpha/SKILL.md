# 个股预期差分析（四象限）

框架：**市场预期端**（`fin.report_forecast` 券商盈利预测：分歧度 CV + 方向）× **基本面端**（`fin.fina_indicator` 边际动量）× **定价端**（`stock.daily_basic` PE/PB 三年分位）× **观点端**（`fin.report_meta` 近期研报）。实现：`beta_alpha/skills/alpha.py`（自治模块；平台对话页意图 `alpha` 自动触发）；本模块让你在 ZCode 会话里直接驱动同一能力。

## 标准用法

项目根目录执行：

```bash
.venv/Scripts/python.exe -m beta_alpha.skills.alpha "中际旭创的预期差"
```

参数是一句话，必须含股票名或 `600519.SH` 格式代码（别名词典 + 正则双路解析）。输出：四象限指标平表 + markdown 中文综述。约 1 分钟（含 LLM 综述）。

## 输出解读口径

| 指标 | 含义 | 判读 |
|---|---|---|
| 预测覆盖 | n 份预测 / n 家机构 | 空覆盖 = 研报库暂无该股绑定（见下方数据现状），如实告知而非硬编 |
| 预测分歧度CV | 同指标同期间预测值离散度（已按单位归一到元） | >0.3 分歧大；越小共识越强 |
| 预测方向 | 后半段均值 vs 前半段 | 上修/下修/持平（±3% 阈值） |
| 营收/净利同比 + 信号 | 最新报告期同比 | 提速/降速（±5pp 阈值） |
| 毛利率 + 信号 | 最新值 | 上行/下行（近2期均值 vs 之前均值） |
| PE(TTM)/PB 分位 | 近 3 年百分位（0=最低） | 低分位=预期保守，高分位=预期已计入 |

预期差的叙事逻辑：**分歧大 + 基本面验证中 + 估值低分位** = 市场尚未定价的争议；**共识强 + 高分位** = 预期已打满。综述由 LLM 按此框架生成，数字一律来自表内。

## 数据现状与边界（必须向用户如实说明）

- `report_forecast` 的 A 股覆盖目前薄弱（研报库以海外券商为主，`ts_code` 绑定率低）。预测象限为空是常态而非故障——明确说"研报库暂无该股盈利预测覆盖"，引导看其余三象限
- 财务动量与估值分位覆盖全 A 股（Tushare 全量），可靠
- 定性信息（管理层指引、在手订单、"CPO 送样"类进展）**不在本框架内**——需要年报正文语料（cninfo 定向爬取，规划中）。用户问及这类内容时说明边界，不要用研报观点硬凑

## 扩展与排障
