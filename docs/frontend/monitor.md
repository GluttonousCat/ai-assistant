# 运行观测（Monitor）

> 侧边栏「实时监控」，仅管理员可用。更新：2026-11-18。

## 系统设计

- `core/observability.py` 提供同步任务装饰器及阶段更新，通过 ContextVar 隔离并发上下文；嵌套任务保留父任务标识。记录写入 `output/observability/runs/`，活动索引写入同级 `active/`，原子替换，不依赖 PG。
- 每次执行持有独立 OS 文件锁。查询时以锁是否仍被持有识别执行进程；异常退出且未写最终回执的记录展示为「已中断」，耗时截至最后更新。活动索引确保长时间静默任务不被最近200条历史窗口挤掉。
- `storage/repositories/observability.py` 读取任务记录、已有回测队列、盘后行情/盘中60F/邮件回执；回测只返回进度摘要，不暴露用户标识、完整策略和请求。页面保留当前任务及最近60条结束记录；观察文件不参与任务调度、断点或交易决策。
- `tools/monitoring.py` 组合本地观测和 PG 状态。PG 最多一个后台探测线程，结果缓存10秒；阻塞探测不会阻塞本地状态推送或不断新增探测线程。鉴权仍按真实数据库角色校验。
- `api/monitor_api.py`：`GET /api/monitor/state`、`POST /api/monitor/stream`（每2秒）和 `GET /api/monitor/logs`，整组 `require_admin`。文件读取放线程池，不在事件循环中同步读盘。
- `web/src/monitor/Monitor.jsx` 保留 Agent 指标；`web/src/monitor/BackgroundMonitor.jsx` 展示后台任务及日志。侧边栏入口及原有权限不变。

## 需求优化

- 默认进入「后台任务」：运行/排队、最近完成、异常数量；展开查看开始时间、更新时间、耗时、阶段和进度。研报可看到下载文件名与反检测等待，区别正常休眠与失败。
- 覆盖研报定时流水线、逐篇下载入库分析、视觉OCR与接续提取、盘后行情与快照、盘中60F采集及扫描、财务报表/分红/披露日期同步、工作台回测队列。
- 「最近回执」独立显示盘后行情目标交易日、盘中轮次/候选数及邮件状态/行情截止，保留真实时间；旧回执不等于当前进程状态。
- 「运行日志」按后台任务、采集工具、领域分析、Agent、API、存储等固定来源，以及级别/关键词筛选。每2秒串行刷新，可暂停、手动刷新或关闭跟随末尾。
- 日志最多读文件尾部256KiB，API最多1000行、页面500行。每次重新打开当前日志，兼容跨日轮转和文件截断；筛选仅作用于该窗口，日志级别为精确匹配，异常堆栈延续上一条日志级别。
- 输出前遮蔽已配置环境密钥、常见密码/token/cookie/授权字段、Bearer/JWT和URL密码；前端按纯文本渲染。只允许固定日志来源，不接受任意路径。

## 问题

| 历史问题 | 根因 | 处理 |
|---|---|---|
| 看不到后台正在做什么 | 原页面仅有进程内Agent指标和PG新鲜度 | 增加跨进程持久任务、阶段、事件和本地日志 |
| PG探测慢时整页首帧迟迟不出 | 原SSE逐帧同步等待探测结果 | 单独后台探测，先返回本地状态；旧探测结果显式标记 |
| 崩溃记录长期显示运行中 | 仅看上次写入的status无法确定进程存活 | 每次执行持有OS租约，结束未回执且租约释放则中断 |
| 下载间隔看起来像卡住 | 反检测会正常等待60～120秒 | 展示具体文件及等待秒数 |

- Agent会话指标仍是内存注册表，重启清零；任务历史保存在本机，与其口径区分。
- 不追溯重建过去未埋点的任务；上线前已有行情/邮件回执和回测记录可直接查看。未埋点的独立CLI仍可通过对应日志查看，不承诺所有历史脚本都有结构化进度。
- 不提供停止/重跑任务按钮，不改采集计划、重试、邮件去重或交易规则。登录和管理员实时角色校验仍需要数据库可用。

## 处理方案

- 新任务使用 `@observed("stable_kind", "中文任务名")`；阶段调用 `task_progress(...)`。已捕获的非致命业务错误通过 `warning=` 标成部分完成；返回显式error/失败状态或抛异常标失败，异常继续向原调用方传播。
- 观测初始化/写盘失败不改变主业务结果。子任务失败传递到父流水线的观测警告；阶段事件每次执行最多40条，页面展开显示最近12条。
- 测试通过根目录 `conftest.py` 把观测写入测试临时目录，避免模拟任务混进真实运行历史。
- 维护时按需归档结束记录；当前版本不自动删除任务档案。原始日志继续沿用 `config.yaml logging` 的轮转保留设置；脱敏作用于观测输出，不修改原始日志文件。
