## 三、本地电脑防护（已具备）

1. 8208 只绑回环，外部无法绕过 Cloudflare 直连
2. cloudflared 出站连接，路由器零端口映射
3. 电脑防火墙默认拦截入站（Windows Defender 默认配置即可）
4. 敏感凭证全在 `.env`（git 忽略）

## 四、PG 服务器加固清单（重要，待执行）

远程 PG（[PG-HOST:REDACTED]）目前**密码认证对全公网开放**，这是最大的暴露面：

1. **改强密码**（若是弱密码/默认密码，改 32 位随机串，同步 .env PG_PASSWORD）
2. **IP 白名单**：pg_hba.conf 限制来源 IP = 本机公网出口 IP（Cloudflare 不代理
   PG 连接，直连 IP 固定），或云安全组只放行 9002 ← 你的 IP
3. 改默认端口 9002 → 随机高端口（可选，配合白名单后非必需）
4. `postgresql.conf: listen_addresses` 不用 `*` 若有内网方案
5. 定期 `pg_stat_activity` 审计异常连接（本档「运维手册」有示例 SQL）

## 五、应用层后续加固（建议优先级）

1. **登录限速**（同 IP 5 次失败锁 10 分钟）——防撞库，当前未做
2. Cloudflare Access 邮箱 OTP 门禁（Zero Trust 免费 50 用户）——登录页完全不露
3. JWT 短有效期（当前 12h）+ refresh token 机制
4. 注册码改为一次性邀请码表（一人一码可撤销），替换单一静态码
