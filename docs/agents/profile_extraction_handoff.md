## 5. 硬规则清单（全部实证换来，缺一条漏一片）

### 5.1 三种排版方言与节定位

| 方言 | 形态 | 代表 | 占比 |
| --- | --- | --- | --- |
| A 准则式 | `## 第X节 ...` 标题 | 澜起688008/药明603259 | 37/55 |
| B 主题式 | `## 公司简介`/`## 主要财务数据及指标` 主题名即节，全篇 0 个"第X节" | 中石化600028（A+H/央企蓝筹: 四大行两桶油险资中芯） | 18/55 |
| C 数字编号式 | `#### 2.1 主要会计数据和财务指标`，## 级只有目录 | 兴业601166 | 含于上者 |

节定位方案（已验证过，被误删，从 git 历史捡回：commit 311d827 的 annual_core.py）：
1. `第X节` 标题锚 **≥4 个** → A 式（注意：目录页会有 1~3 个"第X节"残留，不能 ≥1 就判 A 式——兴业实证踩坑）
2. 否则主题式：**动态选节级** = 取"数量 ≥5 的最浅标题级"（中石化 ## 级；兴业 #### 级）
3. 节名归一（按名匹配不按序号，各家合并节方式不一）：
   `管理层讨论/经营业绩/业务回顾/董事会报告/经营情况/业绩概述/业务概要/未来展望/专项分析→mdna`；
   `公司治理/ESG→governance`；`重要事项→matters`；
   `股东/股份变动→shareholders`；`主要财务数据/主要会计数据/公司简介→summary`；
   `财务报表/财务报告→financial`；`释义→definitions`；`债券→bonds`
4. 节内小节切分 + 关键词过滤（§3 的四/五节规则按 L1 小节标题关键词）

### 5.2 小节切分五规则

1. **标题守卫**：锚定行必须是标记行（带 #/编号前缀）或纯别名行——叙述句
   「报告期末公司前三年主要会计数据和财务指标如下…」会冒充标题（澜起实证）
2. **编号种类判兄弟，# 层数不行**：`#### 六、`(L1) 与 `#### (一)`(L2) 同为 ####，
   兄弟边界必须按编号形态：`一、`=兄弟、`（一）`=子内容（保留）、`N.M`=数字编号兄弟。
   现成实现：`annual_items.marker_rank`（秩：#标题=层数/一、=2.5/N.M=3.0/（一）=3.5，
   边界=下一秩≤标题秩的标记行）
3. **行尾 rstrip**：MD 行尾一个空格就能击穿正则 `$` 锚点（澜起实证）
4. **短节接受**：块 ≥150 字或含表格即收——兴业「2.3 非经常性损益」合法地只有 243 字
5. **词表按实证扩**：中石化叫「非经常性损益项目**及涉及**金额」——遇到新措辞加别名，
   词表是活的最小维护面

### 5.3 清洗规则（annual_items.py 已实现，直接复用）

- 标题：去 `#`/编号/装饰符（`<u>(3)</u>` 的编号在装饰符**之内**，装饰先剥）
- text：剥表格行/**加粗页码**（`**14** / **248**`，装饰必须在页码判断**之前**剥）/
  标题标记行/**全文级页眉集合**（全文出现≥10次的短行=页眉；块内频率法对单次页眉无效）
- tables：`<br>` 去除后跨行词接合；单位行并入 `unit` 字段；内嵌口径行
  （如 `||2025年末|2024年末|`）保留为数据行（承载年度/年末口径切换信息）
- 已知未修：纵向指标表破碎（staff 表头 `['母公司在职员工的数量','','784']` 式），
  纵表解析规则与横表不同，值得单独处理
