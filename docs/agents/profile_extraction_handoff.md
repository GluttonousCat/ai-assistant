## 5. 硬规则清单（全部实证换来，缺一条漏一片）

### 5.1 四种排版方言与节定位

| 方言 | 形态 | 代表 | 处理 |
| --- | --- | --- | --- |
| A 准则式 | `## 第X节 …` | 澜起688008/药明603259 | `第X节/章` 锚 ≥4 判 A 式 |
| A' 章式 | `### **第一章 …**`（粗体+章） | 兴业601166 | 同上（同一正则，剥 \*\*） |
| B 主题式 | `## 公司简介` 等主题名，全篇 0 个"第X节" | 中石化600028（18/55） | 动态选节级 = 可归一节名数 ≥3 的最浅标题级 |
| C 混合式 | 首尾 `第X节` + 中段 `## **管理层讨论 与分析**` | 中建601668 | 锚路径未覆盖的键从任意标题级补 |

- 目录页有 1~3 个"第X节"残留 → **≥4 才判 A 式**（兴业实证踩坑）
- 空标题两行式（华泰 `## 第一节`+下一行 `## 释义`；中建 #####/### 混级）→ 节名取节内首个标题行
- 节名统一剥 \*\*/反引号/勾选框（工行 `` ## **5.** `财务概要` `` 实证）

### 5.2 小节切分规则

1. **编号种类判兄弟，# 层数不行**：`#### 六、`(L1) 与 `#### (一)`(L2) 同为 ####；
   兴业 L1 混用 ####/#####/######。秩：一、=2.5 / N.M=3.0 / N.M.K=3.0+0.1·多段数 /
   （一）=3.5；**顿号后容忍空格**（澜起 `#### 二、 经营…` 曾被判 4.0 深层 →
   块边界塌缩 → risks/top5/capex 漏提取 + business_review 158 字薄壳的根因）
2. **L1 = 节内最浅锚秩**；深层子锚由 `_render_body` 并入父块，子节标题转 `[标题]` 行
   （直接清洗会剥掉标记行标题，澜起「五、(一) 主营业务分析」实证）
3. **边界只认编号锚**：裸 `#` 标题不算边界（兴业第一章 `### 公司组织架构图` 与
   `#### 1.1` 同视觉层级，按 # 层切曾丢内容）
4. **纯文本锚守卫**：≤50 字且不以句读结尾（药明 pymupdf4llm 未标记的标题行）；
   `#` 标记锚放宽到 120 字（澜起 78 字长标题实证）
5. **标题尾勾选框** `√适用□不适用` 先剥（万华600309/中铝601600 实证，曾挤爆
   非标记行守卫致 miss；独立成行时是纯噪声）

### 5.3 第二章相似度兜底

精确别名包含 → 未中时 difflib 归一化比率兜底：标记行 ≥0.75 / 纯文本行 ≥0.85
（长行叙述被结构守卫拦下）。归一化剥空白/标点/数字/**/_/反引号
（`### _2.2.1_ 主要财务数据` 残留 `_` 曾把 0.8 压到 0.71，农行实证）。
**词表仍是权威**：批量审计（`--audit`）输出 fuzzy/miss + 候选行，人工审后固化进词表。
48 份实测词表：kpi3y 8 别名 + nonrecurring 5 别名。
注意：不收「主要财务指标」短别名 — 会把 kpi3y 锚到第二节节标题（澜起实证）。

### 5.4 清洗规则（annual_items.py，items/sections 共用管线）

- 标题：去 #/编号/装饰符（`<u>(3)</u>` 的编号在装饰符**之内**，装饰先剥）/勾选框
- text：剥表格行/页码行（`**14**` 装饰先剥；兴业裸数字页码 `15` 单列守卫）/
  标题标记行/全文级页眉集合（≥10 次短行）/块内频次页眉（≥2 次）
- tables：`<br>` 去除后跨行词接合；单位行并入 `unit` 字段；内嵌口径行
  （`||2025年末|…`）保留为数据行
- 已知未修：纵向指标表破碎（staff 表头 `['母公司在职员工的数量','','784']` 式），
  纵表解析规则与横表不同，值得单独处理
