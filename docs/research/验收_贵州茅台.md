## 一、系统设计

### 1.1 评分卡六维 (达标线抄自任务书, 权重自定)

| 维度 | 度量 | 达标线 | 权重 |
|---|---|---|---|
| 证据覆盖率 evidence_coverage | 数字句中带 `[E:]`/`[V:]` 引用的比例 | ≥80% | 30 |
| 引用有效性 citation_validity | 幽灵引用数 (自查 ∪ flags 报告) | =0 | 20 |
| 结构完整度 structure | 第 1..10 章覆盖 (flags 声明跳过的除外) | 10/10 | 15 |
| 证据丰度 evidence_richness | facts 总数 ≥100 且年报 (`A:` 前缀) 事实 ≥15 | 双达标 | 15 |
| 假设可验证率 hypothesis | hypotheses 含 ≥1 非空指标的比例 | =100% | 10 |
| 三层纯净度 layer_purity | 含 `[V:` 却无机构标注 (行文如事实) 的句子数 | ≤2 | 10 |

**权重理由** (代码内同款注释): 引用闭环 (覆盖率 30 + 有效性 20 = 50 分) 是
"证据可回溯"这条第一铁律的直接度量, 占一半 — 幽灵引用属硬伤, 该维清零;
结构与证据供给 (15+15) 是报告的骨架与原料; 假设可验证 (10) 与三层纯净 (10)
对应方法论"观点不冒充事实 / 假设可证伪", 各占一成。

`score(draft, facts, views, flags) -> {"score": 0-100, "pass": bool, "dimensions": {...}}`;
**pass 与总分独立**: pass = 六维达标线全部满足, 总分 (加权连续值) 供横向比较。
每维返回 `{label, line, weight, ratio, weighted, pass, detail}`, detail 含
`observed` 人读摘要 (如 "数字句引用 40/50 (80.0%)") 供报告直引。

### 1.2 度量口径 (任务书未细化的部分, 由本任务定义并在代码注释留档)

- **句子**: 按 。！？!?；; 与换行切分; markdown 标题行 (`#`)、表格行 (`|`)、
  代码围栏内行不计入句子。
- **数字句**: 剥除行内引用记号后仍含数字 (ASCII/全角) 才算 — `[E:T:2025.x]`
  记号自身的数字不计; `表2 / 图3 / 第4章` 属交叉引用非数据主张, 判定前剥除。
- **三层纯净**: 含 `[V:vid]` 的句子剥记号后, 须出现被引机构名核心词 (剥
  "证券/公司/研究所"等常见后缀, ≥2 字, 如"国泰君安证券"→"国泰君安") 或泛指
  归属词 (机构/券商/研报/分析师/卖方…)。观点动词 (认为/预计) **不构成归属**,
  否则等于放任观点伪装成事实。幽灵 vid 的句子不计入纯净度 (由引用有效性维度
  单独计罚, 不双重扣分)。
- **幽灵引用**: 独立于 T06 复算 — 正文行内引用 + `used_eids` 不在证据集即幽灵,
  前缀非法 (非 `T:/A:/R:`) 同样计入; 再从 flags 文本宽容提取引用记号取并集
  (T06 消息格式未定, 提不出记号就只剩自查结果, 不影响正确性)。
- **跳章豁免**: flags 中同时命中章号 (`第N章/chapter N`) 与跳过关键词
  (跳过/缺失/未生成/略去/省略/skip) 才豁免, 缺章不豁免。
- **flags 参数**: 显式传入优先, `None` 时回退 `draft.flags` (T06 落在 Draft 上的告警)。
- **空转口径**: 全稿无数字句时覆盖率按 1.0 空转通过 (该维度只度量"数字是否带
  引用"); 无 hypotheses 时假设可验证率记 0 分 (判断层缺失不允许)。

## 二、需求优化

任务书给出六维达标线与 `score()` 签名, 落地时做了以下细化 (均为可辩论的设计决策,
已在代码注释留档):

1. **幽灵引用独立复算**: 不依赖 T06 的 flags 消息格式, 评分卡自己扫一遍正文 +
   used_eids (对 flags 只做宽容的记号提取取并集)。评分器与被评对象解耦, T06 输出
   格式变化不破坏评分。
2. **表格行暂不计入覆盖率**: 表格数字句无法优雅携带行内引用, 先排除 (局限见
   问题 4), 由证据丰度 + 引用有效性间接约束。
3. **机构归属用"核心词包含 + 泛指词白名单"双通道**: 兼容"中金公司(2026-03-15)
   认为…"与"多家券商认为…"两种合规写法; 拒绝仅有观点动词的写法。
4. **踩线给分连续化**: 纯净度每句无归属扣 20% (5 句扣光), 覆盖率/结构/丰度按
   比例给分 — 总分可横向比较, pass 仍严格按达标线。
5. **丰度得分 = 两子项 min 截断均值, pass 要求双达标**: 总数 120 条但年报 0 条
   仍不通过 (年报经营数据是方法论硬要求)。
6. **补 `score_from_dir` / `format_report` / CLI**: 目录级一键跑分 + 中文
   markdown 报告, 供 Wave 3 端到端复核与 T08 总装直接复用 (只 import 契约, 不改它)。
