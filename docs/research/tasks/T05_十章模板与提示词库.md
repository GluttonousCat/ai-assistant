# T05 · 十章研究模板与提示词库 (Stage 2 素材)

> 先读 T00。你独占: skills/research/prompts_chapters.py, skills/research/prompts_style.py
> 本任务产出是**数据 (提示词/模板), 不是执行逻辑** — 纯字符串与 dict, 不 import 重模块。

## 目标
把方法论指南的公司研究 10 章结构, 变成可被生成器 (T06) 逐章消费的模板库。

## 实现要点
1. 通读 docs/research/company_industry_guide.md, 提取 10 章定义, 在 prompts_chapters.py 落:

```python
CHAPTERS = [
    {"no": 1, "title": "公司定位与研究结论摘要",
     "question": "这家公司到底是什么? 当前最重要的经营变量是什么?",
     "wants": ["profile", "mainbiz", "views"],   # 需要的证据类别 (供 T06 路由)
     "structure": ["一页公司画像", "3~5个核心研究问题"],
     "length_hint": "600-900字"},
    # ... 共 10 章, 以指南原文为准 ...
]
```

2. prompts_style.py 落全局文风与纪律 prompt (所有章节共用前缀):
   - 三层分离规则: 事实句必须带 [E:eid]; 研报观点句必须带 [V:vid] 且行文用
     "XX机构(日期)认为"; 无证据数字写"待验证"; 判断必须给假设+验证指标。
   - 文风: 机制解释优先于信息罗列 (指南原则2: 经营/竞争/变化/验证四机制);
     禁营销腔; 金额带单位 (亿元/万元); 不做投资建议, 结尾给观察点。
   - 引用格式: 行内 [E:eid] / [V:vid], 渲染层 (T08) 会转成脚注。
3. 每章配 `chapter_prompt(ch, facts_digest, views_digest) -> str` 模板函数
   (只做字符串拼装, 不调 LLM): 含章问题/结构骨架/证据摘要注入位/输出约定。
4. tests: 断言 10 章齐全、每章四字段非空、style prompt 含三层分离关键词 (离线)。

## 验收
pytest 全绿; `python -c "from skills.research.prompts_chapters import CHAPTERS; assert len(CHAPTERS)==10"`

## 禁止
在 prompt 里写死任何公司数据 (模板必须股票无关); import harness/tools/storage。
