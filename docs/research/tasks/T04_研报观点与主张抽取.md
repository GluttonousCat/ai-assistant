# T04 · 研报观点与预测抽取 (Stage 1)

> 先读 T00。你独占: skills/research/sources/report_source.py

## 目标
把研报库中该公司的**观点**整理为 View 分片 — 观点永远不是事实, org+date 是它的身份证。

## 输入 / 输出
- 输入: 股票 (名/代码), 可选回看天数 (默认 365)
- 输出: EvidenceShard(kind="reports", views=[...]) → views_reports.json
- 签名: `def collect_report_views(stock: str, days: int = 365, out_dir: Path | None = None) -> EvidenceShard`

## 实现要点
1. 走 harness.mcp 注册表 (禁直连 SQL):
   `search_reports` (检索清单) → `read_report` (单篇问答取核心观点) →
   `get_forecasts` (盈利预测时序)。
2. View 分类: viewpoint / forecast (必带 period+数值口径) / rating (评级/目标价) / risk。
3. org 归一: `from core.helpers import normalize_org_name` (英文投行名→中文通用名)。
4. 冲突观点都保留 (方法论指南: 多来源交叉, 冲突本身是信息, 不做仲裁)。
5. vid: `R:<report_id>.<seq>`; statement 单句转述、禁改口径; publish_date 用 report_meta 的。
6. CLI: `python -m skills.research.sources.report_source 贵州茅台`

## 验收
茅台: views ≥15, 覆盖 ≥3 机构, forecast 类含期间与单位;
pytest 离线用例 (org 归一 / vid 生成 / 分类校验)。

## 禁止
把 View 写成 Fact 或反之; 修改 mcp 工具; 引入向量库。
