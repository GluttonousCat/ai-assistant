# T09 · 质量评分卡与端到端验收

> 先读 T00。你独占: skills/research/quality_rubric.py, skills/research/tests/test_quality.py,
> docs/research/验收_贵州茅台.md

## 目标
把"优质报告"变成**可度量的分数**; 用茅台案例端到端验证整条生产线并留五段式验收文档。

## 评分卡设计
`quality_rubric.score(draft, facts, views, flags) -> {"score": 0-100, "dimensions": {...}, "pass": bool}`

| 维度 | 度量 | 达标线 |
|---|---|---|
| 证据覆盖率 | 数字句中带 [E:]/[V:] 引用的比例 | ≥80% |
| 三层纯净度 | 含 [V: 却行文如事实 (无机构标注) 的句子数 | ≤2 |
| 假设可验证率 | hypotheses 中含 ≥1 指标的比例 | 100% |
| 结构完整度 | 10 章产出比例 (flags 跳过的除外) | 10/10 |
| 证据丰度 | facts 总数 / 其中年报经营数据数 | ≥100 / ≥15 |
| 引用有效性 | 幽灵引用数 (flags 中) | 0 |

权重自定并在代码注释里说明理由。

## 端到端验收
1. `python -m skills.research 贵州茅台` 全流程跑通;
2. 评分卡跑分并记录;
3. 人工抽读两章, 对照 T03 的复核清单核验证据真实性;
4. 写 docs/research/验收_贵州茅台.md, 项目文档五段式:
   系统设计 → 需求优化 → 问题 → 处理方案 → 验证记录
   (含: 各阶段产物路径、评分、发现的问题清单、下一步建议 — 问题不隐瞒, 全部列出)。

## 验收
评分卡 pytest 离线可测 (fixture 构造满分/踩线样例); 验收文档完成。
