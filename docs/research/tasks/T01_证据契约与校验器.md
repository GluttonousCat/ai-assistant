# T01 · 证据契约完善与校验器

> 先读 docs/research/tasks/T00_总纲_契约与分工.md。隶属: 横切地基。
> 你独占: skills/research/contracts.py, skills/research/tests/test_contracts.py

## 目标
把契约层从"能存取"升级为"能校验": 任何分片/草稿在进入下一 Stage 前可机器检查合法性。

## 实现要点
1. 在 contracts.py 增加纯逻辑校验函数 (不连库不调 LLM):
   - `validate_shard(shard) -> list[str]` (错误清单, 空=合法):
     eid/vid 在分片内唯一且前缀合法 (T:/A:/R:); Fact.layer=="fact"; View.org 与
     publish_date 非空; period 格式合法 (`YYYY`/`YYYYA`/`YYYYH1`/`YYYYQn`/`YYYY-MM-DD`);
     content 含数字时应有 value 或 unit 非空。
   - `validate_draft(draft, facts, views) -> list[str]`: 章节引用的 eid/vid 必须存在于
     证据集; hypotheses 每条至少 1 个 indicator。
2. `pack_stats(facts, views) -> dict`: 按来源(kind 前缀)/期间分布统计, 供 T09 评分卡与调试。
3. 保持既有 API 兼容 (load_pack/save_* 签名与往返行为不变 — 总设计师已自检通过);
   如改字段, 在 T00 末尾"契约变更记录"追加一行。
4. tests/test_contracts.py: 合法/非法 fixture 各 ≥3 例, 覆盖每条校验规则 (纯离线)。

## 验收
```
.venv\Scripts\python.exe -m pytest skills/research/tests/test_contracts.py -q   # 全绿
```
