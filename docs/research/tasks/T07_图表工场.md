# T07 · 图表工场 (Stage 3)

> 先读 T00。你独占: skills/research/compose/figures.py
> 可先于真实证据开工: 用 contracts 构造 fixture 数据开发, 真数据合并后即用。

## 目标
`build_figures(draft, facts, research_dir) -> list[Path]`: 从证据时序自动产出章节配图。

## 实现要点
1. 风格与实现对齐 skills/content/charts.py (可 import 其工具函数, 禁修改它):
   中文无乱码 (字体设置), A股红涨绿跌, 公众号宽度 1080px。
2. 图类型路由:
   - 同指标多年 → 柱状 (财报**累计口径禁止折线连点**!)
   - 产销/利用率双系列 → 分组柱
   - 收入构成 → 占比条形
   - 估值水位 → 区间带
3. 图与章绑定: 按指标类别映射章号 (与 T05 模板 wants 对齐), 文件名 `figs/ch{no:02d}_{slug}.png`;
   返回 (path, chapter_no, 插入位置提示) 清单 — **不改 draft.json**, 由 T08 组装时插入。
4. CLI: `python -m skills.research.compose.figures 600519.SH` (读分片+draft)。
5. pytest: fixture facts → 至少 3 类图生成且文件非空 (离线, matplotlib 用 Agg 后端)。

## 验收
茅台 ≥5 张图, 中文正常, 命名规范; pytest 绿。

## 禁止
改 charts.py / contracts.py; 生成与证据无关的装饰图 (每张图必须可溯源到 facts)。
