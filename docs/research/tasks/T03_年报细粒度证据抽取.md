# T03 · 年报细粒度证据抽取 (Stage 1 · 质量旗舰任务)

> 先读 T00。你独占: skills/research/sources/annual_source.py
> 背景: 现状粗粒度 (annual_items 只到"L1 小节全文"), 本任务把年报变成**原子级证据** —
> 这是报告质量的地基, 全生产线最重要的任务。

## 输入 / 输出
- 输入: output/cninfo/md/<ts_code>/<年>_ndbg_items.json
  (sections: mdna/governance/matters/shareholders → subsections 含标题+全文 md)
- 输出: EvidenceShard(kind="annual") → facts_annual_<年>.json
- 签名: `def collect_annual_facts(ts_code: str, year: int, out_dir: Path | None = None) -> EvidenceShard`

## 抽取目标 (按优先级)
1. **经营数据数字证据** (最有价值 — Tushare 财务表里没有的信息):
   产能/产量/销量/利用率/单价/门店数/在研项目数等经营指标。
   每条: content=单句事实, source=`2025年报·mdna·三、经营情况` (章节+小节锚), value+unit+period。
2. **分部/产品明细**: 分产品/地区收入、成本、毛利率 (第2章素材)。
3. **管理层论断**: 展望/战略/风险应对的原句引用 (判断层素材, 不冒充数值事实)。
4. **风险条目**: 风险因素相关小节逐条原子化。

## 实现要点
1. 每小节一次 LLM 调用 (`harness.llm.get_extract_llm`, JSON 输出, prompt 花括号转义 {{}}):
   输入小节全文, 输出四类原子数组; prompt 纪律: 只抽取原文明确陈述、禁止推断、
   数字原样照抄、每条带小节锚点。
2. 解析宽容 (剥 ```json 围栏); 单小节失败跳过并记入 meta.skipped, 不中断整体。
3. confidence: 原文直引=1.0; 换算 (如同比推算) =0.9 且 source 注明公式。
4. **抽检机制**: 随机 10% 的 facts 生成"人工复核清单" (原句+抽取句对照) 落
   output/research/<ts_code>/annual_review_<年>.md — 质量承诺的可审计形式。
5. eid: `A:<年>.<节>.<小节序号>.<序号>`。
   CLI: `python -m skills.research.sources.annual_source 600519.SH 2025`

## 验收
茅台 2025 年报: facts ≥40 (经营数据类 ≥15); 复核清单可与原文对照;
pytest 离线用例覆盖解析与校验逻辑 (构造小 fixture, 不连 LLM)。
